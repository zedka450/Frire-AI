# Frire
Frire est une IA Française qui marche par Machine Learning. Les serveurs sont situés en France, donc il ne devrait pas y avoir des lags.
Frire est très léger. Il ne vous prendra donc pas beaucoup de place.

## Comment l'installer?
Il y a manières différentes d'installer Frire:

### Option 1 : Mode développeur
Si vous voulez pouvoir voir et modifier le code de Frire, c'est simple.
Dans votre terminal, tapez cette commande:
` git clone [https://github.com/zedka450/Frire-AI.git](https://github.com/zedka450/Frire-AI.git) `

Ensuite, pour lancer Frire, lancez les commandes ci-dessous:
` cd Frire-AI
pip install supabase
python frire.py `

### Option 2 : Mode normal (recommandé)
Si vous voulez juste uttiliser Frire, c'est l'option la plus simple. Téléchargez juste le lien ci-dessous.
[https://github.com/zedka450/Frire-AI/releases/0.1]
